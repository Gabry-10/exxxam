# CVL361 Final Exam Project

## Project Title
Simply Supported Beam Analysis

## Objective
Develop a Python tool to analyze a simply supported beam subjected to a uniformly distributed load and a concentrated load.

## Input Data
- Beam Span = 8 m
- Uniformly Distributed Load = 6 kN/m
- Point Load = 18 kN
- Point Load Location = 5 m from the left support

## Calculations Performed
- Support Reactions
- Shear Force Distribution
- Bending Moment Distribution
- Maximum Bending Moment
- Critical Section Location

## Required Packages
- numpy
- pandas
- matplotlib
- jupyter

## Outputs
- Results Table
- Shear Force Diagram
- Bending Moment Diagram
- Maximum Bending Moment
- Critical Section
